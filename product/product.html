Product Features

QMStudy 能做什么

从读到问、从练到复习，每个环节都落在同一个站点里，并且都由同一套后端与核验流水线支撑。

AI 助教（QuanLLM-v2.0）

鼠标划选正文文字，光标旁浮出小胶囊（✨ 详细解释 / 💬 提问），点击即在右下角面板连续追问。支持 SSE 流式输出、按阶段分组的思考过程、过程时间线、停止生成与重试上一问；选中 AI 回答里的内容还能「引用并追问」。

为什么一维无限深势阱的基态能量不为零？
因为波函数必须在阱壁上连续为零，这个边界条件只允许驻波解，n=1 的驻波对应最小但不为零的动量，于是零点能必然存在。

16 课模块化课程

前言 + 第 1–16 课 + 附录，教材正文、知识点、数学公式与交互动画一一对应。

30 个交互实验

黑体辐射、光电效应、双缝干涉、波包演化、隧道效应、谐振子、氢原子、布洛赫球、Bell 态关联等 Canvas 数值实验。

🦉 引导模式

苏格拉底式追问：AI 不直接给答案，而是判断理解程度、提出反问、只给下一步提示；随时说「直接给答案」即可跳过。

本地账号与学习档案

浏览器内注册 / 登录，密码只做本地 SHA-256 摘要；账号与学习记录仅保存在本机本浏览器的 localStorage。

进度、时长与学习奖状

打开课程自动记为「已学」，顶栏实时显示进度条、已学课数与累计学习时长；学完全部 16 课解锁 🏆 奖状，可打印或存为 PDF。

策略选择与错题回流

掌握度追踪、错题回流、复习任务调度、学情报告与策略实验室，与教材同进程、同端口、同账号。

知识图谱模式

教材之外的第二个入口，用 Cytoscape.js 把 16 课知识点与前置依赖绘成图谱，节点按 6 大知识领域着色，按掌握度分级。

公式划选与笔记

MathJax 采用 CHTML 输出，正文与回答区公式支持字符级划选；划选正文或回答可一键存入学习笔记，按课筛选、编辑并导出 Markdown。

服务端智能体验证（quanllm-harness）

每个问题都由 lct-unv/quanllm-harness 执行「路由 → 双求解器 → 综合 → 断言提取 → 工具证据 → 形式/要求核验 → 裁决 → 定向修复」流水线，逐题独立核验并返回 verified / degraded 状态；模型可调用内置 SymPy、mpmath、算符代数、量纲、边界、角动量与数值工具，精确计算不口算。

01路由 02双求解器 03综合 04断言提取 05工具证据 06形式 / 要求核验 07独立裁决 08定向修复
AI Tutor · Verified Pipeline

答案不是直接给出来的，而是核验过的

浏览器只调用同源接口，模型与工具在后端完成推理与核验；响应以 SSE 逐段推送到 AI 助教面板，思考过程按 Agent 分组显示，不与回答交错。

Getting Started

在本机把整套工作台跑起来

课程内容通过 fetch 动态加载，不能直接双击 index.html（浏览器会拦截本地 fetch），请使用项目自带的 FastAPI 服务托管网页与 AI 代理。

安装与启动
🐍 runtime 推荐 Python 3.11 / 3.12
🌐 port server.py 默认 127.0.0.1:8765（--port 可改）
🖥️ entries 教材 / · 自测 /selftest/ · 报告 /strategy/report · 图谱 /strategy/graph · 实验室 /strategy/lab
💻 快速开始
bash
cd QMStudy_web python -m pip install -r requirements.txt python -m pip install -r requirements-ai.txt # AI 后端（quanllm-harness 完整安装） python server.py # 默认 127.0.0.1:8765 # 然后浏览器访问 http://localhost:8765，注册或登录本地账号即可开始学习
Credentials

首次配置凭据（clone 后必做）

仓库不包含任何真实 API Key，请在项目根目录从模板创建下列文件。两套 AI 使用各自凭据，不要混用。

凭据文件对照（复制自 example 模板后填入真实 Key）
需要创建的文件 复制自 用途
.env .env.example 服务端口、模型等通用配置
APIKEY APIKEY.example 教材 AI 助教（quanllm-harness 流水线）
selftest/.env selftest/.env.example AI 自测模块配置
selftest/APIKEY selftest/APIKEY.example AI 自测模块（非流式、关闭 thinking）

🔑 API Key 写法（按 quanllm-harness README）：在项目根目录新建 APIKEY 文件，文件中只写 Key 本身——不加引号、不加变量名、不写 export。APIKEY 缺失时回退到 .env 的 QMSTUDY_AI_API_KEY；两者都没有时 AI 接口返回 503，课程与其它功能不受影响。

⚙️ 一键运行（Windows）：首次双击 install_and_start.bat（创建 .venv、安装依赖、本地诊断并启动），之后直接双击 start.bat；PowerShell 用户使用 .\install_and_start.ps1 / .\start.ps1。

🔒 安全边界：账号体系是仅用于隔离同机同浏览器学习档案的本地私人账号，不提供真实服务器鉴权；服务端只托管静态文件与 /api/ai/answer，无会话、无 Cookie、无数据库。接口面向本机使用设计，若要暴露到局域网或公网，请自行加访问控制，否则任何人都能消耗你的 AI 额度。凭据文件均被 .gitignore 排除，请勿分享或公开仓库。
